Panduan Pinout Arduino Uno R3 (ATmega328P)

Referensi cepat fungsi pin fisik mikrokontroler untuk keperluan perancangan skema rangkaian elektronik SMK TEI.

Pin Daya (Power Pins)

  • 5V: Output daya ter-regulasi 5 Volt DC.
  • 3.3V: Output daya 3.3V (Maks 50mA).
  • GND: Ground / Sumbu Nol Volts.
  • VIN: Input tegangan eksternal (7V - 12V DC).

Digital I/O & PWM

  • Pin 0 - 13: Pin Digital Input/Output (HIGH/LOW).
  • PWM Pin (~3, 5, 6, 9, 10, 11): Sinyal Modulasi Lebar Pulsa (8-bit: 0-255).
  • Pin 0 (RX) & 1 (TX): Komunikasi Serial UART Hardware.
  • Pin 2 & 3: Interupsi Eksternal (INT0 & INT1).

Analog Input & Komunikasi I2C

  • Pin A0 - A5: Input Analog ADC 10-Bit (Nilai: 0 hingga 1023).
  • Pin A4 (SDA): Serial Data Protocol I2C (LCD/Sensor).
  • Pin A5 (SCL): Serial Clock Protocol I2C.
  • AREF: Tegangan referensi eksternal ADC.

Rumus Penting Rangkaian Mikrokontroler TEI

1. Hambatan Resistor Seri LED

R = (V_CC - V_LED) / I_LED

Contoh: Vcc=5V, Vled=2V, I=20mA (0.02A) → R = 3V / 0.02A = 150 Ω (Gunakan standar 220 Ω).

2. Perhitungan Resolusi Tegangan ADC

V_in = (Nilai_ADC / 1023.0) * 5.0 Volt

Resolusi per-step ADC = 5V / 1023 = 4.88 mV per nilai integer.
